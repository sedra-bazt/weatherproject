# 🌤️ Weather Forecast App (Next.js)

تطبيق ويب حديث ومتجاوب للحصول على حالة الطقس وتوقعات الأيام القادمة مباشرة عبر واجهة برمجية (Weather API)، مصمم ومطور باستخدام **Next.js**.

---

## 🚀 الميزات الرئيسية (Features)

* 🔍 **بحث فوري:** البحث عن حالة الطقس لأي مدينة في العالم.
* 🌡️ **بيانات طقس حية:** عرض درجة الحرارة المباشرة، نسبة الرطوبة، سرعة الرياح، والضغط الجوي.
* 📅 **التوقعات المستقبلية:** عرض توقعات درجات الحرارة وحالة الجو للأيام القادمة.
* ⚡ **أداء عالي:** سرعة تحميل فائقة وتجربة مستخدم سلسة بفضل SSR/ISR في Next.js.
* 📱 **تصميم تجاوبي بالكامل:** ملائم للشاشات المختلفة (الهواتف، الأجهزة اللوحية، والحواسيب).

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Framework:** [Next.js](https://nextjs.org/) (React)
* **Styling:** Tailwind CSS / Flowbite
* **API Integration:** Weather API (Fetch / Axios)
* **Icons:** Lucide React / React Icons
